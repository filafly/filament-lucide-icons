# CLAUDE.md

Lucide icon pack for Filament 4 and 5, built on the filafly/filament-icons core.

- `src/LucideIcons.php`: the plugin. `$iconMap` maps every Filament icon alias to a `Lucide` case. Keys are alias strings, not `*IconAlias` constants, because some constants only exist in later 4.x releases.
- `src/Enums/Lucide.php`: generated by `php bin/generate-icon-cases.php` from mallardduck/blade-lucide-icons. Don't edit by hand.
- Lucide has one style, so there is no style enum.

Commands: `composer test` (PHPUnit + Testbench), `vendor/bin/pint`. The ship gate runs `npm test`, which runs composer update then PHPUnit.

`LucideIconsTest::test_every_filament_alias_is_mapped` fails when a new Filament release adds an alias: map it in `$iconMap`.
